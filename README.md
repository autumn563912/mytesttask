# Описание проекта

- Приложение представляет собой веб-сервер, возвращающий в ответ на http-запрос сообщение "Hello Effective Mobile". В качестве основного веб-сервера используется Python-пакет `http.server`. Для обработки проксирования и балансировки входящего трафика приложение использует `nginx` прокси-сервер, который принимает внешние запросы и передаёт их основному серверу. В качестве окружения для работы сервера используется Docker.

- Файловая структура приложения:

  - `./` - корневой каталог, содержит файл `docker-compose.yaml` для единовременного запуска компонентов, а также может содержать файл `.env` для хранения переменных окружения;
  - `./backend/` - содержит файл `app.py` для конфигурации основного веб-сервера, а также `Dockerfile` для сборки сервера в контейнере;
  - `./nginx/` - содержит файл `nginx.conf`, содержащий конфигурацию nginx прокси-сервера, а также `Dockerfile` для сборки nginx в контейнере;


- Схема взаимодействия компонентов приложения:
  
```

                   +-------------------------------------[ Host ]--------------------------------------+
                   |                                                                                  |
                   |                    +------------------[ Docker network ]----------------------+  |
                   |                    |                                                          |  |
+------------+     |--------------+     |--[ Docker-container ]--+     +--[ Docker-container ]--+  |  |
|  localhost | <-> : HOST_PORT=80 : <-> :        NGINX           : <-> :    Python: http.server |  |  |
+------------+     |--------------+     |------------------------+     +------------------------+  |  |
                   |                    |                                                          |  |
                   |                    +----------------------------------------------------------+  |
                   |                                                                                  |
                   +----------------------------------------------------------------------------------+
```

- Технологический стек:
  - Python 3.13
  - docker 28.2.2
  - docker-compose 1.29.2
  - nginx 1.29.5
 
# Запуск проекта

* Установить `docker:28.2.2` и `docker-compose:1.29.2`
 
* Загрузить файлы репозитория:

```
git clone https://github.com/autumn563912/mytesttask.git
```

* Находясь в директории с файлами репозитория, собрать контейнеры:

```
docker-compose build
```

* При необходимости создать файл `.env` и указать порт, на котором будет работать приложение. Если не создавать данный файл, то приложение будет использовать по умолчанию порт 80:
```
touch .env && echo "HOST_PORT=<порт приложения>">.env
```

* Запустить приложение:
```
docker-compose up -d
```

* Для остановки приложения:
```
docker-compose down
```

# Проверка работы приложения

* Для проверки работы приложения в адресной строке браузера необходимо ввести `http://localhost:<порт приложения>`, где `<порт приложения>` - номер порта, указанный в файле `.env` или порт 80, в случае если файл `.env` отсутствует. Если приложение функционирует, то вы увидите надпись `Hello Effective Mobile!`.

* Для проверки работоспособности через консоль ввести:
```
curl http://localhost:<порт приложения>
```  
В качестве ответа приложение выведет в терминал `Hello Effective Mobile!`
