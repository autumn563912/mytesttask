# Запуск проекта

1. Установить 'docker ' и 'docker-compose '
 
2. Загрузить файлы репозитория:

'''
git clone
'''

3. Находясь в директории с файлами репозитория, собрать контейнеры:
'''
docker-compose build
'''

4. При необходимости создать файл '.env' и указать порт, на котором будет работать приложение:
'''
touch .env && echo "HOST_PORT=<порт приложения>">.env
'''

5. Запустить приложение:
'''
docker-compose up -d
'''

6. Для остановки приложения:
'''
docker-compose down
'''
